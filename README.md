# Catálogo Norelle SV

Sitio web de catálogo para Norelle SV.

## Tecnologías
- HTML5, CSS3, JavaScript
- Bootstrap 5 (recomendado para navegación fácil)
- ASP.NET Core con Entity Framework Core (para base de datos)
